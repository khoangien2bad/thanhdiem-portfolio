# Portfolio — Nguyễn Thị Thanh Diễm

Landing page portfolio cá nhân. Social Marketing Executive.

## Cách chạy
Mở `index.html` bằng trình duyệt. Không cần cài gì, không cần build.

## Cấu trúc
```
index.html              toàn bộ trang: HTML, CSS, JS trong một file
assets/                 71 ảnh .webp theo tên slot + 18 logo .png
assets/fonts/           font Manrope tự chứa, chạy được khi không có mạng
assets/lg/              bản ảnh lớn cho lightbox
assets/video/           9 video .mp4
.github/workflows/      tự động deploy lên GitHub Pages khi push vào main
```

## Đổi ảnh
Đặt file mới vào `assets/` trùng tên slot là xong, không cần sửa code.
Trang tự dò lần lượt các đuôi `.webp` `.jpg` `.jpeg` `.png`.

Muốn biết ô nào tên gì: mở trang, bấm nút **Chế độ góp ý** ở góc dưới bên phải,
mỗi ô ảnh sẽ hiện tên slot của nó.

## Bật GitHub Pages
Settings → Pages → Source chọn **GitHub Actions**. Push vào `main` là tự deploy.

## Nguồn nội dung
Toàn bộ chữ lấy nguyên văn từ bản Canva của Diễm. Không viết lại, không rút gọn.
